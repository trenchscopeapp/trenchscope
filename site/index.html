Your analyst reads the screen you are reading.

Press a and your own claude or codex login gets the same tool results, through a read-only MCP server.

Labelled
Every answer is marked model output, with the age of every number it used.
Untrusted input

Read-only

Keyboard only.

Every screen answers to the same few keys. Press ? for the rest.

  • jk

    Move through rows on any list.

  • enter

    Open the coin: chart, holders, tape and safety.

  • a

    Ask the analyst about what is on screen.

  • /

    Filter with plain thresholds: vol24 > 250K liq > 50K

  • w

    Watch a coin and set alerts, stored on your machine.

  • c

    Chart in a docked window or your browser.

  • esc

    Back to where you came from.

  • q

    Quit. Nothing keeps running.

Open a terminal.

On a Mac, open Terminal from Spotlight. On Windows, open PowerShell from the Start menu. Run doctor first: it checks Node, your terminal, the optional claude login and every data source, and prints the exact fix for anything missing. Then trenchscope opens the app on paper.

Do I need an API key?

Core market data works without a key. An optional Helius RPC key unlocks holder data and a faster on-chain lane. Fields that need a missing key say needs key. See the data sources.

Do I need an AI subscription?

The screener works without an AI login. The built-in analyst uses your own logged-in Claude Code or Codex account, and usage is billed to that account. Connect your assistant.

Can the analyst send a trade?

No. The analyst and MCP server have no build, sign or send tool. Every run starts on paper. A live trade needs your keypress and approval in your own wallet. Read the safety rules and known issues.

What if setup fails?

Run trenchscope doctor in Terminal or PowerShell. It checks your setup and data sources, then prints the fix for anything missing. For an assistant connection, run trenchscope mcp doctor.
