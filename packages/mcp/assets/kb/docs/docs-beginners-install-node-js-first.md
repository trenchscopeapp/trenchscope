dexterm needs Node.js 22.18 or newer. Node.js is the program that runs dexterm. Check whether it is already installed:

```sh check Node.js
node -v
```

Output such as `v22.18.0` or a larger version is ready. If the command is missing or the number is lower, install the current **Long-Term Support (LTS)** release—the version maintained for ordinary users—from nodejs.org (https://nodejs.org/), close the terminal, reopen it, and run `node -v` again.
