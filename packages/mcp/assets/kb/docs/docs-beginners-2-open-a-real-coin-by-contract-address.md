A **contract address**, often shortened to **CA**, is the long public identifier for a coin. It is public information, not a wallet secret.

Press `g`. A small **go-to prompt** appears inside dexterm. Paste this DEXTERM project-token example and press Enter:

```text DEXTERM project token example
2huJ1cxDXpGrh2bPYxptaoLj89to8CnzdVC5aYTEpump
```

This is the verified address of the optional DEXTERM memecoin launched by the dexterm authors. It is not part of the software and has no utility or rewards. It appears here only as a stable public-address example, not as a recommendation or endorsement. Not financial advice. Verify the address before using it. You can instead use the verified public address of any Solana coin you choose.
