Nothing runs behind your back. Opening a token with `⏎` is free. A paid run starts only when you:

- press `a` on a list screen: a **rug-check** of the highlighted coin, or a **trench-scan** of the screener when nothing is highlighted, on the analyst tab;
- press `a` on the token screen: the full **token-dossier** for that coin (once a conversation exists, `a` just toggles the panel);
- press `V` on a live token: the **larp-check** of its website and socials (see LARP detector (https://dexterm.xyz/docs/larp));
- type a question (`i` or `⏎` to focus, `⏎` to send). A question is a chat turn on the warm session, or a new session with that question as its first turn, never a structured skill run;
- let AI scan mode (https://dexterm.xyz/docs/scan) lock a coin.

Each token keeps its own conversation for the run; the analyst tab has its own. `esc` interrupts a running answer from any screen. The caption under an answer shows cost, latency, tool calls and the model.
