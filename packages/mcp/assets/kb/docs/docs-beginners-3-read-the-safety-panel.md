The coin's **token screen** opens. Find the **ON-CHAIN / SAFETY** area. “On-chain” means information read from Solana's public record. Read each source and its age.

- **Mint authority** says whether someone can create more tokens.
- **Freeze authority** says whether someone can freeze token accounts.
- **Liquidity** is the pool available for buying and selling.
- A **risk flag** points out a condition to inspect. It is not proof that a coin is safe or unsafe.

If a value says unavailable or stale, treat it as unknown. Never turn missing data into a pass.
