Every source the app reads, what it takes from each, the keyless limits, and what a free key adds.

dexterm must stay usable forever with **no paid data and no shipped keys**: Node, a terminal and your own Claude login are enough. Every data need has a keyless path on a public API and degrades honestly; a free key you make yourself only raises speed or limits or unlocks depth, it never gates a feature. Because every source meters by **your** IP or key, each user has their own quota and there is no shared server in the middle.
