The **holder** panel describes how ownership is distributed. `top 10` means the share held by the ten largest counted accounts. A pool or exchange account can distort that number, so read the labels and the sample note too. A concentrated supply is a reason to investigate, not a verdict.

Press `?` at any time to see the keys that work on the current screen. Press `Esc` to close help or go back.
